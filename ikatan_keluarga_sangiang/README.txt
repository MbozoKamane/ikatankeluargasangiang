IKATAN KELUARGA SANGIANG JABODETABEK
======================================

CARA MENJALANKAN:
1. Install XAMPP.
2. Copy folder "ikatan_keluarga_sangiang" ke:
   C:\xampp\htdocs\
3. Jalankan Apache.
4. Buka:
   http://localhost/ikatan_keluarga_sangiang/
5. Untuk login admin:
   http://localhost/ikatan_keluarga_sangiang/admin/login.php

LOGIN DEMO:
Username : admin
Password : admin123

DATABASE:
1. Buka phpMyAdmin.
2. Buat/import database.sql.
3. Database bernama: iks_jabodetabek

CATATAN GAMBAR:
Folder assets berisi gambar yang dipakai website.
Ganti file JPG dengan foto asli organisasi tanpa perlu mengubah kode,
selama nama file tetap sama.
